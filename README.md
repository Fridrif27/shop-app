# Shop App

Shop App is a web application for product management, built using React, TypeScript, and Vite.

## Features
- View the list of products  
- Add new products  
- Edit existing products  
- Delete products  
- Add and remove comments on products  
- Sort products by name or quantity  

## Technologies
- React  
- TypeScript  
- Vite  
- Tailwind CSS  
- Axios for HTTP requests  
- JSON Server for backend simulation  

## Installation

Clone the repository:

```sh
git clone https://github.com/your-username/inforce-shop.git
cd inforce-shop

Install dependencies:
npm install

Start JSON Server (in a separate terminal):
json-server --watch data/db.json --port 3001

Run the application:
npm run dev
